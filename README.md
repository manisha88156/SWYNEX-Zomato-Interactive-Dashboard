# SWYNEX Task 3: Zomato Interactive Dashboard

## Project Overview

This project was completed as part of my Data Analyst internship tasks at SWYNEX Technologies Pvt. Ltd.

The objective of this project is to build an interactive Power BI dashboard to analyze Zomato delivery performance, order distribution, and factors affecting delivery time.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- Data Visualization
- Interactive Slicers and KPI Cards
- CSV Dataset

## Dashboard Features

- **Total Orders:** Displays the total number of orders analyzed.
- **Average Delivery Time:** Shows the average time taken for deliveries.
- **Traffic Density Analysis:** Compares average delivery time across traffic conditions.
- **Weather Analysis:** Examines delivery time across different weather conditions.
- **Vehicle Type Analysis:** Compares delivery performance across vehicle types.
- **City Category Analysis:** Shows order distribution across city categories.
- **Order Type Analysis:** Analyzes order counts by order type.
- **Monthly Order Analysis:** Shows order distribution across the months available in the dataset.
- **Interactive Filters:** Enables users to explore results by traffic density, weather conditions, and festival status.

## Key Findings

- The dataset contains 45,584 orders.
- The overall average delivery time is approximately 26.29 minutes.
- Orders recorded under Jam traffic conditions have an average delivery time of approximately 31.18 minutes.
- Orders recorded on festival days have an average delivery time of approximately 45.52 minutes.
- Weather conditions and vehicle types show differences in average delivery time.

These findings describe the available dataset and do not necessarily establish that any single factor causes delivery delays.
